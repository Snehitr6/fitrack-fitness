# 💪 FitTrack – Fitness Tracker Website

FitTrack is a modern, responsive fitness tracker website built with React, Vite, and Tailwind CSS. It helps users track workouts, monitor fitness progress, calculate BMI, explore nutrition information, and manage fitness goals through a professional, dark-themed interface.

## ✨ Features

- **Modern UI:** Responsive design with a dark theme, lime-green accents, and smooth animations.
- **Animated Preloader:** Cinematic fitness-themed opening screen with an online gym background image.
- **Dashboard:** View workout activity, completed workouts, and fitness statistics.
- **Workout Library:** Explore workout categories, difficulty levels, durations, and estimated calories burned.
- **Workout Timer:** Start, pause, resume, and complete workouts with a countdown timer.
- **Workout History:** Save completed workout sessions in browser local storage.
- **Progress Tracking:** Visualize workout progress and activity trends using charts.
- **BMI Calculator:** Calculate Body Mass Index using height and weight.
- **Nutrition Section:** Explore nutrition information and healthy lifestyle tips.
- **Fitness Goals:** Review and manage personal fitness targets.
- **Scroll Animations:** Sections and cards reveal smoothly as users scroll.
- **Responsive Layout:** Designed for desktops, tablets, and mobile devices.
- **Accessibility:** Supports reduced-motion preferences.

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
- Lucide React
- Recharts
- CSS Animations
- Browser Local Storage
- Unsplash for online fitness imagery
